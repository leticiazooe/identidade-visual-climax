# Identidade Visual — CLIMAX Refrigeração

Repositório de ativos da identidade visual da **CLIMAX Refrigeração**.

## Mascotes

Os mascotes ficam em `assets/mascotes/` e foram organizados por uso:

- principal / corpo inteiro
- círculo / busto
- apontando / CTA
- positivo / avaliações e pós-venda
- técnico / manifold e climatização
- técnico / condensadora

As imagens em WebP mantêm transparência e foram otimizadas para uso digital em site, landing pages, redes sociais e campanhas.
