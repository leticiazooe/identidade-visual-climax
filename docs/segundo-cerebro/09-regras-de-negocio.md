# 09 — Regras de negócio

Última revisão: 2026-09-21

## Regras comprovadas

1. O repositório é oficial para ativos visuais da CLIMAX Refrigeração — evidência no README principal.
2. Mascotes são arquivos PNG em assets/mascotes/.
3. O README atribui usos sugeridos diferentes às 10 poses.
4. A direção visual documentada prevê ilustração 2D/cartoon, uniforme azul institucional, logo CLIMAX REFRIGERAÇÃO e foco em climatização/refrigeração.
5. Logos possuem variantes azul e branca em PNG/SVG.

## Regras ainda não formalizadas

**PRECISA DE VALIDAÇÃO HUMANA**
- cor oficial primária versus cor apenas presente no arquivo;
- fundo mínimo e contraste;
- margens/área de proteção;
- tamanho mínimo;
- distorção, recoloração e efeitos permitidos/proibidos;
- quando usar mascote versus logo sem mascote;
- regras de co-branding;
- tipografia;
- direitos de modificação e redistribuição.

Até serem aprovadas, não tratar inferências visuais como norma de marca.
