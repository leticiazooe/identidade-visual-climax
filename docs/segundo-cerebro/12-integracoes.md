# 12 — Integrações

Última revisão: 2026-09-21

**NÃO LOCALIZADO**

Não há código de integração com:
- APIs;
- e-mail;
- CMS;
- site;
- CDN;
- storage externo;
- Figma/Adobe;
- automações de redes sociais;
- banco;
- webhooks.

O GitHub é o único sistema externo necessário para versionamento e colaboração.

Se um site consumir estes assets por URL raw/CDN, documentar o contrato e evitar substituir arquivos existentes sem versionamento, pois isso pode alterar consumidores silenciosamente.
