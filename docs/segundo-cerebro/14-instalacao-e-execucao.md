# 14 — Instalação e execução

Última revisão: 2026-09-21

O projeto não possui runtime.

## Para trabalhar localmente

1. Clonar o repositório GitHub.
2. Entrar na pasta identidade-visual-climax.
3. Atualizar a main com git pull.
4. Criar uma branch de trabalho.
5. Adicionar ou editar assets/documentação.
6. Revisar git status e diff.
7. Commitar e enviar a branch.

Não existem comandos de instalação, servidor local, build ou execução de aplicação.

## Visualização

- PNG: qualquer visualizador de imagens;
- SVG: navegador moderno, Figma, Illustrator, Inkscape ou editor compatível;
- Markdown: GitHub, VS Code ou editor Markdown.
