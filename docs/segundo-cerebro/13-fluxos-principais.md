# 13 — Fluxos principais

Última revisão: 2026-09-21

## Fluxo atual de inclusão de asset

1. Criar/exportar o asset.
2. Colocar na categoria correta em assets/.
3. Revisar nome, formato e variante.
4. Atualizar documentação se o uso mudar.
5. Criar commit descritivo.
6. Preferencialmente abrir PR para revisão.
7. Após aprovação, integrar à main.

## Fluxo de consumo

1. Identificar o tipo de material.
2. Selecionar a variante adequada.
3. Preferir SVG para escala vetorial e PNG quando raster/transparência for necessária.
4. Preservar proporção.
5. Não inferir regras de cor/uso ainda não documentadas como oficiais.

## Fluxo de mudança de identidade

Mudanças em cor, forma ou nomenclatura devem gerar novo registro de decisão, atualização de assets, revisão do README e atualização deste segundo cérebro.
