# 18 — Segurança e privacidade

Última revisão: 2026-09-21

Não foram localizados tokens, arquivos de ambiente ou segredos na estrutura auditada.

## Riscos específicos

- ativos podem conter propriedade intelectual e direitos de imagem;
- mascotes podem ter sido produzidos a partir de referências pessoais; o README menciona inspiração em características físicas fornecidas como referência;
- ausência de LICENSE ou termos de uso deixa permissões de redistribuição ambíguas.

## Regras

- não versionar credenciais;
- não registrar dados pessoais desnecessários;
- documentar direitos de uso de logos, fontes, ilustrações e fotografias;
- revisar metadados de arquivos antes de publicação externa quando aplicável.
