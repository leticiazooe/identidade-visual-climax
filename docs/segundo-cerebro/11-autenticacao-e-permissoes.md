# 11 — Autenticação e permissões

Última revisão: 2026-09-21

Não há autenticação ou autorização implementada no conteúdo do repositório.

O controle de acesso é externo e pertence ao GitHub/repositório:
- leitura conforme visibilidade do repositório;
- escrita conforme permissões concedidas no GitHub;
- revisão por Pull Request quando adotada.

**NÃO LOCALIZADO**: CODEOWNERS, regras de branch versionadas, matriz de papéis ou política de aprovação dentro do repositório.

Recomendação: proteger main e exigir revisão para alterações de logo, paleta ou ativos considerados oficiais.
